# Mi lista — práctica de listas HTML

Página para aprender `<ol>`, `<ul>` y listas anidadas.

## Qué hace

- Ejemplos de listas ordenadas y con viñetas
- Algunos estilos en `css/estilos.css`
- Highlight.js para el código de ejemplo

## Cómo probarlo

Abre `index.html`.

Demo: https://moussijoelle.github.io/Mi-lista/

## Cómo lo construí

HTML + CSS. Sin lógica JS de aplicación.

## Cómo verificarlo

Reviso que las listas se vean ordenadas y legibles.
