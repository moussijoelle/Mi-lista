# Mi lista — listas HTML

Página de práctica de listas HTML: ordenadas, con viñetas y anidadas.

## Qué hace

- Ejemplos de `<ol>`, `<ul>` y listas anidadas
- Estilos en `css/estilos.css`
- Highlight.js para bloques de código

## Cómo probarlo

Abre `index.html` o la demo (no necesita JavaScript de app).

Demo: https://moussijoelle.github.io/Mi-lista/

## Cómo lo construí

- HTML + CSS
- Enlaces a documentación de listas

## Cómo verificarlo

Sin tests. Reviso que las listas se vean bien en el navegador.
